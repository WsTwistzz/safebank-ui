# SafeBank · Refined Experience

基于 48378b2。客户侧移动银行，黑白金，中文。保留原有会话、业务服务、转账预演与二次授权；不伪造余额、投资收益和实时曲线。用户已授权自主制定设计细节。

## 方向
温暖纸白 #F1F2EF、纯白 #FFFFFF、石墨 #111318、次级灰 #6E6C66、香槟 #E7D7A4。系统无衬线与等宽数字。信息左对齐，主金额 40px 左右，正文不低于 13px，操作至少 44px。首屏一个深色资产主卡，其他内容保持轻白。玻璃集中到浮动导航和操作层。无金属环，无持续旋转装饰。

首页：身份与问候 → 总资产及隐私按钮 → 基于实际余额的资产分布 → 四个常用入口 → 小安建议入口 → 订阅提醒、交易、月账单。点击资产分布打开可关闭的明细面板，金额隐藏在全部新元素中一致生效。近期交易可按全部/支出/收入筛选。小安打开预填需求，需用户主动发送后才生成计划。

全局：修复过小字号与目标尺寸；底部导航使用一个轻玻璃胶囊，中间小安保留黑金主入口；登录、银行卡、理财和个人页面统一圆角、间距与材质。银行卡以代码绘制纹理和芯片，不改变掩码与安全操作。主题、减少动态效果与减少透明度均保留。

验证：类型、生产构建、现有测试，以及新交互针对性测试；能运行浏览器时补充320/390/430与桌面的布局、溢出和键盘验收。无浏览器渲染则明确记录，不冒充截图验收。
